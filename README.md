# Simpsoteca

Plataforma de streaming personal estática, compatible con GitHub Pages. Almacena todo localmente en el navegador usando IndexedDB. Diseño inspirado en Apple TV.

## Características

- 🎬 Catálogo de películas y series
- 📺 Soporte de temporadas y episodios
- 🔍 Búsqueda y filtros por género
- 🔖 Mi Lista (favoritos)
- ▶ Reproductor HTML5 con progreso guardado
- 📥 Importación de archivos TXT (archivo o pegado manual)
- 🎨 Portadas automáticas desde TMDB
- 💾 Backup y restauración en JSON
- 📱 Optimizado para iPad, iPhone, Android y escritorio
- 🌐 Funciona como PWA instalable

## Requisitos

- Navegador moderno: Safari 15+ / Chrome 89+ / Firefox 89+
- API key gratuita de TMDB (para portadas automáticas)
- Cuenta de GitHub (para publicar en GitHub Pages)
